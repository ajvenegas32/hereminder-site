HereMinder store data

HereMinder ships with a table of stores built from OpenStreetMap. This page offers that table and the program that builds it, as the Open Database License requires.

Notice

This database is derived from OpenStreetMap data (Geofabrik extract of 2026-09-24) and is made available under the Open Database License 1.0. Any rights in individual contents of the database are licensed under the Database Contents License. © OpenStreetMap contributors — openstreetmap.org/copyright. It includes HereMinder's category, convenience, big-format and parking-lot columns, which are offered under the same license. Built by HereMinder's build.py (published below, with StoreTable-format.md, the byte layout).

Download

  • StoreTable.bin — the table as shipped in the current HereMinder build (OSM data of 2026-09-24; the date is in the file header, bytes 8–15).
  • StoreTable-format.md — the byte layout.
  • LICENSE-ODbL.md — the license text and what is offered.

How it is built

  • build.py, storetable.py
  • category-map.json, chain-carries.json
  • big-format-brands.json, brand-categories.json, brand-destinations.json, convenience-fragments.json
